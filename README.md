## Getting Started

### Prerequisites

- **Node.js 20+**
- **npm 10+**
- Git
- Optional: Docker

### Installation

```bash
git clone <your-github-repository-url>
cd <project-folder>
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```

---

## Environment Variables

Create a `.env.local` file and add the required environment variables for your project.

```env
DATABASE_URL=
NEXT_PUBLIC_SITE_URL=https://kalsariya-krish.vercel.app
```

Add other API keys or service credentials only when required by the corresponding project features.

---

## Deployment

The portfolio can be deployed using:

- **Vercel**
- **Docker**

For Vercel deployment:

```bash
npm run build
```

Then connect the GitHub repository to Vercel and configure the required environment variables.
